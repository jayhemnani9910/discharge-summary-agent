# reference/

Ground-truth artifacts produced once by a vision model reading all 71 scanned pages of
`data/patient2/source.pdf`. These are not generated by the agent; they are inputs/checks.

- **`ground_truth_transcript.json`** — the page-by-page vision transcription (verbatim
  text, document type, dates, entities, and per-page flags). This is the OCR output. It is
  what `--transcript` feeds into the agent when no live vision provider is available, e.g.:

  ```bash
  python -m discharge_agent run --chat-provider deepseek \
      --transcript reference/ground_truth_transcript.json --patient patient2
  ```

  With a Gemini vision key, the agent regenerates an equivalent transcript itself from the
  PDF (`--pdf data/patient2/source.pdf`); the content comes from the same pages either way.

- **`ground_truth_map.json`** — a synthesized clinical map (timeline, the diagnosis
  conflicts, the medication changes, the pending labs, open questions). Used to sanity-check
  that the agent's draft surfaces the real issues. Not consumed by the code.
